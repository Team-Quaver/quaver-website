# 花火插件（Sparkle）

花火插件是 Quaver Music 的插件系统。插件可以在不改动 Quaver 本体的情况下扩展它：往侧栏加自己的页面、给正在播放页换逐字歌词渲染、接入备用播放源、给歌曲右键菜单加操作、自定义主题、在设置页提供自己的设置项。

## 内置插件

Quaver 自带两个预装插件，默认启用，可随时停用：

- **Apple Music-like Lyrics**：用 AMLL 渲染逐字歌词（卡拉OK扫色，支持 QRC / TTML）。只对带逐字时间轴的歌曲生效，其余歌曲不受影响；停用后回到行级歌词。
- **Die For You 歌词**：示例插件，在设置页随机展示一句《Die For You》歌词。

## 管理插件

所有插件在 **设置 → Sparkle** 里管理，分 主题 / 插件 / 扩展 / Marketplace 四个相互隔离的标签：

- **主题**：已安装的主题（开关启停提供它的插件；主题有自身高级选项时，行内会出现设置按钮）。切换主题直接去 **设置 → 外观 → Sparkle 主题**。
- **插件**：已装插件逐个启用 / 停用（第三方插件可卸载）；行内的齿轮按钮打开该插件的设置。
- **扩展**：已安装的扩展，管理方式与插件相同。
- **Marketplace**：浏览与安装（可按 全部 / 主题 / 插件 / 扩展 筛选），以及「添加本地插件」入口。

Marketplace 的索引源固定为 `https://quaver.0w0.red/marketplace.json`（官方提供，不可更改），点「刷新」拉最新。

## 主题

提供主题的插件启用后，会出现在 **设置 → 外观 → 花火面具** 里（该选项只在有插件主题可用时出现），点选即生效；选「默认」回到普通外观。插件主题是在原有明暗模式之上叠加的一层配色，未覆盖的部分仍跟随你选的明暗模式。Sparkle 面板的「主题」标签只负责启停主题插件本身，日常切换不用去那里。

## 安装第三方插件

三种方式：

1. **Marketplace**：在 设置 → 花火插件 → Marketplace 里直接安装（索引源固定为官方提供的静态 JSON，点「刷新」拉最新）；装好的内容会按分类归入 主题 / 插件 / 扩展 标签。
2. **添加本地插件**：Marketplace 标签里的红色「添加本地插件」按钮，选择一个单文件 ESM `.js` 插件。点击后会先弹出红色警告弹窗，倒计时 5 秒后才能确认——Quaver 不审查、也不推荐手动安装插件，请自行确认来源与内容安全。
3. **开发调试**：把插件目录放进 Quaver 配置目录的 `plugins/` 下，或用 `QUAVER_SPARKLE_DIR` 指定目录。

插件安装后默认关闭，需手动启用。

## 安全须知

第三方插件会在本地运行任意代码、可以访问页面数据。Quaver 对插件没有沙箱隔离，安装前请确认来源可信——只安装你信任的作者发布的插件。
