# 插件系统（Sparkle）

Sparkle 是 Quaver Music 的插件系统。插件可以在不改动 Quaver 本体的情况下扩展它：往侧栏加自己的页面、给正在播放页换逐字歌词渲染、接入备用播放源、给歌曲右键菜单加操作、自定义主题、在设置页提供自己的设置项。

## 内置插件

Quaver 自带两个官方插件，默认启用，可随时停用：

- **Apple Music-like Lyrics**：用 AMLL 渲染逐字歌词（卡拉OK扫色，支持 QRC / TTML）。只对带逐字时间轴的歌曲生效，其余歌曲不受影响；停用后回到行级歌词。
- **Die For You 歌词**：示例插件，在设置页随机展示一句《Die For You》歌词。

## 管理插件

所有插件在 **设置 → Sparkle** 里管理：

- **已装插件**：逐个启用 / 停用；第三方插件可以卸载。
- **插件设置**：各插件提供的设置项（如 AMLL 的逐字歌词开关）。

## 主题

提供主题的插件会出现在 **设置 → 外观 → Sparkle 主题** 里（该选项只在有插件主题可用时出现），点选即生效；选「默认」回到普通外观。插件主题是在原有明暗模式之上叠加的一层配色，未覆盖的部分仍跟随你选的明暗模式。

## 安装第三方插件

两种方式：

1. **Marketplace**：在设置 → Sparkle → Marketplace 填入索引源 URL，刷新后直接安装。索引源是一个静态 JSON，任何人都可以自建；默认索引源由 Quaver 官方提供。
2. **本地手装**：把插件目录放进 Quaver 配置目录的 `plugins/` 下（或开发时用 `QUAVER_SPARKLE_DIR` 指定目录）。

插件安装后默认关闭，需手动启用。

## 安全须知

第三方插件会在本地运行任意代码、可以访问页面数据。Quaver 对插件没有沙箱隔离，安装前请确认来源可信——只安装你信任的作者发布的插件。
