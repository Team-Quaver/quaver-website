# 下载

感谢您选择 Quaver Music，以下为下载链接。

如果您是中国大陆用户，请使用 gh-proxy 进行下载。

[![Github](https://img.shields.io/badge/github-blue?logo=github&style=for-the-badge)](https://github.com/Team-Quaver/quaver-music/releases/latest)

与此同时，我们推荐 Linux 用户通过如意玲珑商店，星火应用商店下载应用，享受通过统一管理器更新。

## 支持以下平台：

### Linux

- X86-64（适合 AMD / Intel / 兆芯 / 海光平台）
	- `Quaver-{version/版本}-amd64.deb` （适合 Debian/Ubuntu/AOSC/Deepin/银河麒麟）
	- `Quaver-{version/版本}-x86_64.rpm` （适合 Fedora/openSUSE/EL 兼容发行版）
	- `Quaver-{version/版本}-x86_64.AppImage` （适合支持 AppImage 的发行版）
	- `Quaver-{version/版本}-x86_64.flatpak` （适合支持 Flatpak 的发行版）
- ARM（适合飞腾、海思、高通骁龙、NVIDIA Spark 平台）
	- `Quaver-{version/版本}-arm64.deb` （适合 Debian/Ubuntu/AOSC/Deepin/银河麒麟）
	- `Quaver-{version/版本}-aarch64.rpm` （适合 Fedora/openSUSE/EL 兼容发行版）
	- `Quaver-{version/版本}-arm64.AppImage` （适合支持 AppImage 的发行版）
	- `Quaver-{version/版本}-aarch64.flatpak` （适合支持 Flatpak 的发行版）
- 龙芯
	- `Quaver-{version/版本}-loong64.deb` （适合 Debian/Ubuntu/Deepin/银河麒麟）
	- `Quaver-{version/版本}-loongarch64.rpm` （适合 openSUSE/Loongix/Fedora/EL 兼容发行版）
	- `Quaver-{version/版本}-loongarch64.deb` （适合 AOSC）

:::warning 警告
龙芯的 Electron 版本为 34，可能对 Wayland 兼容并不友好，与此同时，该版本为实验性版本，存在打包的一些问题
:::
### Windows

推荐使用 Windows 10 21H2 及其以后的版本。

- X86-64（适合 AMD / Intel / 兆芯 / 海光平台）
- ARM（适合高通骁龙，NVIDIA Spark 平台）
### macOS

仅限 macOS 14 之后的版本，我们目前并不计划针对 Intel 世代的设备做支持。

- ARM（适合 Apple Silicon M 系列芯片）
